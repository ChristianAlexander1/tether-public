# Third-party notices

TermX currently contains only original source and the supplied specifications. The planned external components are recorded below and must be added with their full upstream copyright and license text when vendored or linked.

| Component | License policy | Integration status |
|---|---|---|
| SwiftTerm | MIT | Attach source/package before production UI release |
| ios_system | BSD 3-Clause | Attach fork and notice before native command release |
| mksh or dash | MirOS/BSD | Attach selected shell source and notice |
| CPython | Python Software Foundation | Attach iOS build artifacts and notice |
| nodejs-mobile / Node.js | MIT | Attach iOS build artifacts and notice |
| wasm3 or WasmKit | MIT/Apache-2.0 | Attach runtime and notice |
| Blink | ISC | Attach emulator and notice before Linux lane release |
| JetBrains Mono / Fira Code | SIL Open Font License | Attach font files and OFL text if shipped |

GPL and AGPL code must not be bundled. Claude Code is user-installed under the user's own Anthropic agreement and is launched rather than redistributed.
